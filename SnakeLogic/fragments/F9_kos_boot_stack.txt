--- the anchor this fragment gives us ---

frame 7 (android.app.Instrumentation.newApplication) is the injection point:
it is the last framework frame before the app's own Application class is
constructed. For SNAKE that class is com.snake.App (F3: application), whose
<clinit> contains the committed loadLibrary('engine') site at
classes.dex+0x2b6c2e (F2). So the spine can be stitched at exactly this frame:

    T0 frame 7  Instrumentation.newApplication        [shape — this fragment]
    T1 hop 1    com.snake.App.<clinit>()V             [proven — F3 + F2]
    T1 hop 2    classes.dex+0x2b6c2e loadLibrary      [proven — F2]
